Run these commands from the repository root using Python 3.11.
The manifests are authoritative; do not reinstall older package pins from previous notes.

py -3.11 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r apps/requirements.txt
Set-Location .\apps\api
& ..\..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000 and consult README.md for model assets and configuration.
This is a local research prototype. Full OCR/model execution and deployment security require separate validation.
